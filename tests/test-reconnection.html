⚠️ Important: This test requires multiple browser tabs/windows to simulate different players.

📋 Test Instructions:

1 Start the server: cd pokerv2/server && npm run dev
2 Open this test page in multiple browser tabs/windows (at least 3)
3 Join the game with different players (use different names)
4 Click "Ready" for all players and start the game
5 Wait for cards to be dealt and the game to start
6 When it's a player's turn, close their browser tab to simulate disconnection
7 Wait for the game to continue with remaining players
8 Reopen the closed tab and rejoin the game with the same player name
9 Verify that the reconnected player can make turns normally
10 Verify that the reconnected player's cards are restored

📝 Expected Behavior

  • Disconnection Handling: When a player disconnects, they should be marked as folded but not completely removed
  • Game Continuation: The game should continue with remaining players
  • Reconnection: When a player reconnects with the same name, they should be restored to the game
  • Turn System: Reconnected players should be able to make turns normally
  • Card Restoration: Reconnected players should have their cards restored
  • Game State: The game should maintain its state during disconnection/reconnection
  • Notifications: Should show appropriate messages for disconnection and reconnection

🔧 Technical Details

  • Player Tracking: Players are tracked by name for reconnection
  • Socket Management: Socket IDs are updated on reconnection
  • Game State: Game continues with active players only
  • Card Management: Cards are hidden during disconnection, restored on reconnection
  • Turn Logic: Disconnected players are marked as folded, reconnected players can act normally

🐛 Troubleshooting

  • Reconnection fails: Ensure using the same player name
  • Turn issues: Check browser console for error messages
  • Cards not restored: Verify game is still in progress
  • Server connection: Ensure server is running on port 3000
  • Multiple players needed: Test requires at least 2-3 players
