🎰 Poker Game - Disconnect/Connect Logic Test

This page tests the new robust disconnect/connect logic that allows seamless reconnections.

🔄 New Disconnect/Connect Logic
The new system provides intelligent handling of disconnections and reconnections:

🎯 Key Features:

  • Smart Room Resets: Only reset room when necessary (not enough players)
  • Seamless Reconnections: Players can reconnect without losing their spot
  • Game State Preservation: Game continues if enough players remain
  • Intelligent Notifications: Different messages for disconnect vs leave
📋 Test Scenarios

Scenario 1: Lobby Disconnection

  1. Have 2+ players in lobby (not ready)
  2. One player disconnects (close tab)
  3. Verify: Room resets, remaining players see reset notification
  4. Player reconnects (reopen tab)
  5. Verify: Room resets again, all players can continue

✅ Expected:

  • Room resets on disconnect (not enough players for game)
  • Room resets on reconnect (new player joining)
  • All players see appropriate notifications

Scenario 2: Game in Progress Disconnection

  1. Start a game with 3+ players
  2. One player disconnects during betting
  3. Verify: Player is marked as folded, game continues
  4. Player reconnects
  5. Verify: Player rejoins with same cards, can continue playing

✅ Expected:

  • No room reset (game continues)
  • Disconnected player is folded
  • Reconnecting player gets same cards and position
  • Other players see disconnect/reconnect notifications

Scenario 3: New Player During Game

  1. Start a game with 2-3 players
  2. Try to join with a new player (different browser)
  3. Verify: New player gets "Game in progress" error
  4. Wait for game to end
  5. Try joining again
  6. Verify: New player can join after game ends

✅ Expected:

  • New players cannot join during active game
  • Clear error message: "Game is in progress"
  • New players can join after game ends

Scenario 4: Multiple Disconnections

  1. Start a game with 4 players
  2. Two players disconnect
  3. Verify: Game ends (not enough active players)
  4. One player reconnects
  5. Verify: Room resets to lobby

✅ Expected:

  • Game ends when too many players disconnect
  • Room resets when reconnecting player returns
  • All players can start a new game
