🎮 Spectator Functionality Test

Test Overview

This test verifies that players who join a room during an active game are properly treated as spectators and cannot participate in the game mechanics.

🧪 Test Scenario 1: New Player Joins During Active Game

Test that a new player joining during an active game is marked as a spectator and cannot participate.

Test Steps:

  1. Start the server: cd pokerv2/server && npm start
  2. Open the game in two browser windows/tabs
  3. In the first window, join as "Player1"
  4. In the second window, join as "Player2"
  5. Start the game (both players should be ready automatically)
  6. Once the game is in progress (cards dealt, betting round started), open a third browser window
  7. In the third window, join as "Player3"
  8. Observe the behavior of Player3

Expected Results:

  • Player3 should be marked as a spectator in the server logs
  • Player3 should see "[SPECTATOR]" next to their name in the UI
  • Player3 should NOT receive any cards
  • Player3 should NOT be able to click any action buttons (fold, call, raise, all-in)
  • Player3 should NOT receive turns
  • Player3 should be able to see the game progress and chat

🔄 Test Scenario 2: Player Reconnects During Active Game

Test that a player who disconnects and reconnects during an active game remains as a spectator.

Test Steps:

  1. Start with a 3-player game in progress
  2. Have Player1 disconnect (close browser tab/window)
  3. Wait a moment for the server to detect the disconnect
  4. Have Player1 reconnect (open new browser window and join with same name)
  5. Observe Player1's behavior after reconnection

Expected Results:

  • Player1 should be marked as a spectator after reconnection
  • Player1 should see "[SPECTATOR]" next to their name
  • Player1 should NOT be able to make any actions
  • Player1 should be able to see the game progress
  • The game should continue normally for the other players

🔍 Server-Side Verification

Check the server console logs to verify spectator handling.
// Expected server logs when a new player joins during active game: 🆕 New player Player3 joining... 👁️ Player Player3 joined as spectator during active game // Expected server logs when a player reconnects during active game: 🔄 Player Player1 reconnecting... 👁️ Reconnected player Player1 remains as spectator during active game

🎯 Key Implementation Details

The spectator functionality is implemented through several mechanisms:
// Server-side spectator marking isSpectator: isGameInProgress // Mark as spectator if joining during game // Server-side action prevention if (player.isSpectator) { throw new Error('Spectators cannot make actions'); } // Server-side active player filtering getActivePlayers() { return Array.from(this.players.values()).filter(p => !p.folded && !p.disconnected && !p.isSpectator ); } // Client-side action prevention if (myPlayer && myPlayer.isSpectator) { console.log('FastGameScene: Spectators cannot make actions'); return; }

⚠️ Important Notes

Spectator Conversion: Spectators are only converted to active players when:
  • The game ends and returns to lobby state
  • A new game starts (all spectators become active players)
Spectator Benefits: Spectators can:
  • Watch the game in real-time
  • Use the chat system
  • See all player actions and cards (when revealed)
  • Join the next game as an active player

🔧 Troubleshooting

If the spectator functionality is not working as expected:
  1. Check server console for spectator-related logs
  2. Verify that isSpectator flag is being set correctly
  3. Check that action buttons are properly disabled for spectators
  4. Ensure that getActivePlayerOrder() excludes spectators
  5. Verify that reconnection logic preserves spectator status
