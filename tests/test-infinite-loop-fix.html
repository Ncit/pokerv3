🔄 Infinite Loop Fix Test

Testing the fix for infinite loop when all players call after community cards are dealt

🐛 Problem Description

When all 5 community cards are on the deck and all players click "call" (or "check"), the game gets stuck in an infinite loop with repeated "check" actions being logged in the server console.

⚠️ Symptoms:

  • Server console shows repeated "check" actions in a loop
  • Game doesn't progress to showdown
  • Players can't take actions
  • Betting round never completes

🔧 Root Cause Analysis

Issue Identified:

  • Betting Round Completion Logic: The `isBettingRoundComplete()` method wasn't correctly detecting when all players had equal bets and had acted
  • Infinite Loop in startBettingRound(): When skipping folded/all-in players, the method could call `nextPlayer()` which might trigger `nextPhase()` and then call `startBettingRound()` again
  • Phase Transition Logic: The `nextPhase()` method always called `startBettingRound()` even when the betting round was already complete

Problematic Code (Before Fix):

startBettingRound() {
    // Skip folded/all-in players
    while (this.isCurrentPlayerFoldedOrAllIn()) {
        this.nextPlayer(); // This could cause infinite loop
    }
}

nextPlayer() {
    if (this.isBettingRoundComplete()) {
        this.nextPhase(); // Calls startBettingRound() again
    } else {
        this.startBettingRound(); // Could cause loop
    }
}

✅ Solution Implemented

Fixes Applied:

  • Enhanced startBettingRound(): Added checks for betting round completion before and after skipping players
  • Improved nextPlayer(): Added condition to prevent calling startBettingRound() during phase transitions
  • Enhanced isBettingRoundComplete(): Added better logic for detecting when all players have acted and all bets are equal
  • Added Debug Logging: Comprehensive logging to track betting round completion and phase transitions

Fixed Code (After Fix):

startBettingRound() {
    // Check if betting round is already complete
    if (this.isBettingRoundComplete()) {
        this.nextPhase();
        return;
    }

    // Skip folded/all-in players
    while (this.isCurrentPlayerFoldedOrAllIn()) {
        this.nextPlayer();
        
        // Check again if betting round is complete after skipping players
        if (this.isBettingRoundComplete()) {
            this.nextPhase();
            return;
        }
    }
}

nextPlayer() {
    if (this.isBettingRoundComplete()) {
        this.nextPhase();
    } else {
        this.currentPlayer = nextPlayer;
        // Only start betting round if not in phase transition
        if (this.phase !== 'showdown') {
            this.startBettingRound();
        }
    }
}
