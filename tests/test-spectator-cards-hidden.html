🃏 Spectator Cards Hidden Test

Test Overview

This test verifies that spectator players do not have their cards displayed during gameplay, ensuring that spectators cannot see any player's cards until they are revealed during showdown.

🧪 Test Scenario: Spectator Cards Hidden During Gameplay

Test that spectator players do not have any cards displayed during normal gameplay phases.

Test Steps:

  1. Start the server: cd pokerv2/server && npm start
  2. Open the game in three browser windows/tabs
  3. In the first window, join as "Player1"
  4. In the second window, join as "Player2"
  5. Start the game (both players should be ready automatically)
  6. Once the game is in progress (cards dealt, betting round started), open a third browser window
  7. In the third window, join as "Player3" (spectator)
  8. Observe the card display for all players

Expected Results:

  • Player1 and Player2 should have their cards displayed (face down for others, face up for themselves)
  • Player3 (spectator) should NOT have any cards displayed
  • Player3 should see "[SPECTATOR]" next to their name
  • Player3 should not be able to make any game actions
  • Console should show: "FastGameScene: Hiding cards for spectator player: Player3"

🔄 Test Scenario: Reconnected Player Cards Hidden

Test that a player who disconnects and reconnects during an active game has their cards hidden.

Test Steps:

  1. Start with a 3-player game in progress
  2. Have Player1 disconnect (close browser tab/window)
  3. Wait a moment for the server to detect the disconnect
  4. Have Player1 reconnect (open new browser window and join with same name)
  5. Observe Player1's card display after reconnection

Expected Results:

  • Player1 should be marked as a spectator after reconnection
  • Player1 should see "[SPECTATOR]" next to their name
  • Player1 should NOT have any cards displayed
  • Player1 should not be able to make any actions
  • Console should show: "FastGameScene: Hiding cards for spectator player: Player1"

🎯 Test Scenario: Showdown Card Revelation

Test that during showdown, all players' cards are revealed (including spectators who had cards).

Test Steps:

  1. Start with a 3-player game in progress
  2. Have Player1 disconnect and reconnect (becoming a spectator)
  3. Continue the game until showdown phase
  4. Observe card revelation during showdown

Expected Results:

  • During showdown, all players' cards should be revealed
  • This includes spectators who had cards when they were active players
  • Cards should be displayed face up for all players to see
  • Winning cards should be highlighted with a golden tint

🔍 Implementation Details

The spectator card hiding functionality is implemented in several key methods:
// In updatePlayerCards() - Hides cards for spectators if (player.isSpectator) { console.log('FastGameScene: Hiding cards for spectator player:', player.name); this.cardManager.safeClearPlayerCards(elements.playerNumber); return; } // In dealHoleCards() - Skips card display for spectators if (player.isSpectator) { console.log('FastGameScene: Skipping card display for spectator player:', player.name); return; } // In revealAllPlayersCards() - Shows all cards during showdown // This method still works for spectators during showdown

⚠️ Important Notes

Card Visibility Rules:
  • Spectators do not see any cards during normal gameplay
  • Spectators can see all revealed cards during showdown
  • Reconnected players become spectators and lose card visibility
  • Spectators become active players when new games start
Security Benefits:
  • Prevents spectators from gaining unfair information
  • Maintains game integrity and fairness
  • Ensures only active players can see their cards
  • Allows spectators to watch the game without interfering

🔧 Troubleshooting

If spectator cards are still being displayed:
  1. Check browser console for spectator-related logs
  2. Verify that player.isSpectator is true for spectator players
  3. Ensure updatePlayerCards() is being called with correct parameters
  4. Check that cardManager.safeClearPlayerCards() is working properly
  5. Verify that the spectator flag is being set correctly on the server

📋 Test Checklist

Use this checklist to verify the spectator card hiding functionality:
  • ✅ New spectators joining during game have no cards displayed
  • ✅ Reconnected players (spectators) have no cards displayed
  • ✅ Spectators see "[SPECTATOR]" label
  • ✅ Spectators cannot make game actions
  • ✅ Console shows appropriate spectator card hiding logs
  • ✅ Active players still see their cards normally
  • ✅ Cards are revealed for all players during showdown
  • ✅ Spectators become active players when new games start
