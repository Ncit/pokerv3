🔄 Call Loop Debug Test

Issue Description

You encountered a call loop issue after implementing spectator functionality and button repositioning. This test helps identify and fix the problem.

🔍 Debugging Steps

Follow these steps to identify the source of the call loop:

Step 1: Check Browser Console

  1. Open the game in a browser
  2. Open Developer Tools (F12)
  3. Go to the Console tab
  4. Look for these specific log messages:
// Look for these messages in console: "FastGameScene: updateUI called recursively, preventing loop" "FastGameScene: updateActionButtons called recursively, preventing loop" "FastGameScene: Player is spectator - disabling actions" "FastGameScene: Hiding cards for spectator player: [Name]"

Step 2: Identify the Trigger

  1. Start the server: cd pokerv2/server && npm start
  2. Open the game in two browser windows
  3. Join as different players
  4. Start a game
  5. Open a third browser window and join as a spectator
  6. Monitor the console for call loop messages

🔧 Fixes Applied

The following fixes have been applied to prevent call loops:

1. Call Stack Protection in updateUI()

// Added protection to prevent recursive calls if (this._updatingUI) { console.log('FastGameScene: updateUI called recursively, preventing loop'); return; } this._updatingUI = true; // ... method body ... finally { this._updatingUI = false; }

2. Call Stack Protection in updateActionButtons()

// Added protection to prevent recursive calls if (this._updatingActionButtons) { console.log('FastGameScene: updateActionButtons called recursively, preventing loop'); return; } this._updatingActionButtons = true; // ... method body ... finally { this._updatingActionButtons = false; }

3. Fixed Button Creation

// Changed from using 'call' button type to 'raise' with custom config this.startGameButton = this.buttonManager.createButton('raise', 120, 120, { scale: 0.3, interactive: true, cursor: 'hand' });
