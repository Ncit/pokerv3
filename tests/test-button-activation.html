🎮 Button Activation Test

Test Overview

This test verifies that all poker action buttons (Fold, Call, Raise, All-In) are properly enabled when it's the player's turn, regardless of raise limits or other conditions.

🧪 Test Scenario: All Buttons Enabled on Turn

Test that all action buttons are enabled and clickable when it's the player's turn.

Test Steps:

  1. Start the server: cd pokerv2/server && npm start
  2. Open the game in two browser windows
  3. Join as different players (Player1, Player2)
  4. Start the game
  5. When it's Player1's turn, verify all buttons are enabled
  6. Click each button to verify they respond
  7. Check console for activation messages

Expected Results:

  • All four buttons should be enabled and clickable
  • Button text should be white (#ffffff)
  • Console should show: "FastGameScene: All buttons enabled - it is my turn"
  • Console should show: "FastGameScene: All action buttons enabled"
  • Each button click should trigger the corresponding action

🔍 Test Scenario: Raise Button with Limits

Test that the raise button remains enabled even when raise limits are reached.

Test Steps:

  1. Start a game with multiple players
  2. Reach the raise limit (3 raises per round)
  3. When it's your turn, verify the raise button is still enabled
  4. Click the raise button to see if it still works
  5. Check the visual indication (text color)

Expected Results:

  • Raise button should be enabled and clickable
  • Raise button text should be gray (#888888) to indicate limit
  • Console should show: "FastGameScene: Raise limit reached - button enabled but visually indicates limit"
  • Clicking raise should still send the action (server will validate)

🎯 Test Scenario: Button States During Game

Test button states during different phases of the game.

Test Steps:

  1. Start a game and observe button states
  2. When it's NOT your turn, verify buttons are disabled
  3. When it IS your turn, verify buttons are enabled
  4. After making an action, verify buttons are disabled
  5. When it becomes your turn again, verify buttons are re-enabled

Expected Results:

  • Not my turn: All buttons disabled, gray text
  • My turn: All buttons enabled, white text
  • After action: All buttons disabled, gray text
  • Turn returns: All buttons re-enabled, white text

🔍 Troubleshooting

If buttons are not activating properly:
  1. Check Console: Look for activation/deactivation messages
  2. Verify Turn State: Ensure isMyTurn() returns true
  3. Check Player State: Ensure player is not folded or all-in
  4. Verify Game Phase: Ensure game is not in showdown
  5. Check Spectator Status: Ensure player is not a spectator
  6. Inspect Button Elements: Verify buttons exist and are properly created
