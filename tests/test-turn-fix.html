🧪 Test Turn Tracking Fix

🎯 Test Objective
Verify that when a player leaves the room and the remaining players start a new game, the turn tracking works correctly and players can make actions without getting "Not your turn" errors.
🔧 What Was Fixed
The issue was that when players left the room, they were marked as disconnected but not removed from the `playerOrder` array. This caused the game to use incorrect player indices when calculating whose turn it was.
Fixes Applied:
  1. Updated `startNewHand()` to use only active players (excluding disconnected ones) for position calculations
  2. Updated `handlePlayerAction()` to validate turns using active player order
  3. Updated `nextPlayer()` to use active player order for turn progression
  4. Updated `nextPhase()` to use active player order for starting player calculation
  5. Updated `isCurrentPlayerFoldedOrAllIn()` to use active player order
  6. Added `postBlindById()` method for posting blinds by player ID instead of position
  7. Updated `dealHoleCards()` to only deal to active players
📋 Test Steps
  1. Open the multiplayer game in 3 different browser tabs/windows
  2. Join the game with 3 different players (e.g., Player 1, Player 2, Player 3)
  3. All players click "Ready" and then "Start Game"
  4. Play a few rounds of poker normally
  5. Close one of the browser tabs (simulating a player leaving)
  6. In the remaining 2 browser tabs, verify that the room resets to lobby state
  7. Both remaining players click "Ready" and "Start Game" again
  8. Verify that both players can make actions (fold, call, raise, all-in) without getting "Not your turn" errors
  9. Complete the hand and verify the game works normally
✅ Expected Results
Before Fix: After a player left and the remaining players started a new game, players would get "Not your turn" errors when trying to make actions.
After Fix: After a player leaves and the remaining players start a new game, both players should be able to make actions normally without any turn-related errors.
⚠️ Important Notes
Server Restart Required: Make sure to restart the server after applying the fixes so that the updated PokerGame.js code is loaded.
Multiple Browser Sessions: Use different browser sessions or incognito windows to simulate different players joining the game.
