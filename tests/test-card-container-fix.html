🃏 Card Container Fix Test

Testing the fix for "CardManager: No container found for player X" errors

🐛 Problem Description

The error "CardManager: No container found for player 1" was occurring during game initialization when the system tried to clear card containers that hadn't been created yet.

Root Cause:

  • Initialization Order: Card containers were being cleared before they were created
  • Error Logging: CardManager was logging errors for missing containers during normal initialization
  • Player Numbering: The system was trying to clear containers for players 1-6 regardless of whether they existed

🔧 Fix Implementation

1. Fixed Initialization Order in FastGameScene.js

Modified `initializePlayers()` method to only clear containers that actually exist:

Before (Problematic Code):

// Clear all existing card containers
for (let i = 1; i <= 6; i++) {
    this.cardManager.clearPlayerCards(i);
}

After (Fixed Code):

// Store existing player numbers before clearing
const existingPlayerNumbers = Array.from(this.playerElements.values())
    .map(elements => elements.playerNumber)
    .filter(number => number !== undefined);

// Clear existing players
this.playerElements.clear();

// Clear existing card containers (only if they exist)
existingPlayerNumbers.forEach(playerNumber => {
    this.cardManager.safeClearPlayerCards(playerNumber);
});

2. Added Safe Clear Method in CardManager.js

Created `safeClearPlayerCards()` method that doesn't log errors for missing containers:

New Safe Clear Method:

safeClearPlayerCards(playerNumber) {
    const containerKey = `player${playerNumber}_cards`;
    const containerData = this.cardContainers.get(containerKey);
    
    if (!containerData) {
        return false; // No error logging
    }

    // Destroy all card sprites
    containerData.cards.forEach(cardData => {
        containerData.container.remove(cardData.sprite);
        cardData.sprite.destroy();
    });

    // Clear cards array
    containerData.cards = [];

    if (this.isDebug) {
        console.log(`CardManager: Safely cleared all cards for player ${playerNumber}`);
    }

    // Emit cards cleared event
    eventManager.emit('cards_cleared', playerNumber);

    return true;
}

3. Updated All Clear Calls

Replaced all `clearPlayerCards()` calls with `safeClearPlayerCards()` to prevent error logging:

Updated Method Calls:

// In handleNewHand()
this.playerElements.forEach((elements, playerId) => {
    this.cardManager.safeClearPlayerCards(elements.playerNumber);
});

// In updatePlayerCards()
this.cardManager.safeClearPlayerCards(elements.playerNumber);
