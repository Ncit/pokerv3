🎰 Poker Game - Hide Disconnected Players Test

This page tests the new functionality to hide disconnected players and their cards from the UI.

👻 Hide Disconnected Players Feature
When a player disconnects, their avatar, name, bank, and cards are hidden from the UI while keeping them in the game for potential reconnection.

🎯 What Gets Hidden:

  • Player Avatar: Hidden when disconnected
  • Player Name: Hidden when disconnected
  • Bank Display: Hidden when disconnected
  • Player Cards: Hidden when disconnected
  • Name Background: Hidden when disconnected

🔄 What Happens on Reconnection:

  • All UI Elements: Become visible again
  • Cards: Reappear with same state
  • Player State: Maintained (folded/active)
  • Notification: Shows reconnection message
📋 Test Scenarios

Scenario 1: Lobby Disconnection

  1. Have 2+ players in lobby
  2. One player disconnects (close tab)
  3. Verify: Player avatar, name, and cards disappear
  4. Player reconnects (reopen tab)
  5. Verify: All UI elements reappear

Scenario 2: Game in Progress Disconnection

  1. Start a game with 3+ players
  2. One player disconnects during betting
  3. Verify: Player and cards disappear, game continues
  4. Player reconnects
  5. Verify: Player and cards reappear, maintains folded state

Scenario 3: Multiple Disconnections

  1. Start a game with 4 players
  2. Two players disconnect
  3. Verify: Both players and their cards disappear
  4. One player reconnects
  5. Verify: Only that player reappears

📊 Expected Results

✅ When Player Disconnects:

  • Player avatar becomes invisible
  • Player name text disappears
  • Bank amount disappears
  • Player cards disappear
  • Name background disappears
  • Notification shows: "Player отключился. Ожидание переподключения..."

✅ When Player Reconnects:

  • All UI elements become visible again
  • Cards reappear in same state
  • Player maintains their game state (folded/active)
  • Notification shows: "Player переподключился!"
🔧 Technical Implementation
New Methods Added:
  • hideDisconnectedPlayer(playerId) - Hides all UI elements for disconnected player
  • showReconnectedPlayer(playerId) - Shows all UI elements for reconnected player
  • hidePlayerCards(playerNumber) - Hides card container
  • showPlayerCards(playerNumber) - Shows card container
Event Handling:
  • playerDisconnected event triggers hide functionality
  • playerReconnected event triggers show functionality
