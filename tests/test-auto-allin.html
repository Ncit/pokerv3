Testing the new feature that automatically converts insufficient raises to all-in actions

🔄 Auto All-In Logic

When a player tries to raise but doesn't have enough money for the minimum raise amount, the system now automatically converts the action to an all-in instead of showing an error.

How it works:

  • Minimum Raise Calculation: System calculates the minimum required raise amount
  • Fund Check: Compares player's bank with the additional amount needed
  • Auto Conversion: If insufficient funds, automatically sends all-in action
  • Seamless Experience: Player doesn't see errors, action proceeds smoothly

📝 Implementation Details

FastGameScene.js - handleRaise() method:

// Check if player has enough money for the minimum raise
if (myPlayer.bank < totalBetAmount - myPlayer.currentBet) {
    // Player doesn't have enough for minimum raise, make it all-in
    console.log('FastGameScene: Insufficient funds for minimum raise, making all-in');
    this.networkManager.sendPokerAction('allIn', myPlayer.bank);
} else {
    // Player has enough money, proceed with normal raise
    this.networkManager.sendPokerAction('raise', totalBetAmount);
}

AIBotScene.js - handleRaise() method:

// Check if player has enough money for the minimum raise
const additionalAmountNeeded = raiseAmount - currentPlayer.currentBet;
if (currentPlayer.bank < additionalAmountNeeded) {
    // Player doesn't have enough for minimum raise, make it all-in
    console.log('AIBotScene: Insufficient funds for minimum raise, making all-in');
    this.raisePlayer(currentPlayer.id, currentPlayer.bank);
} else {
    // Player has enough money, proceed with normal raise
    this.raisePlayer(currentPlayer.id, raiseAmount);
}

🎯 Test Scenarios

Scenario 1: Preflop with Low Bank

Setup: Current bet: $0, Big blind: $20, Player bank: $15

Action: Player clicks "Raise" button

Expected Result: System automatically sends all-in action with $15

Why: Minimum raise ($20) > Player bank ($15)

Scenario 2: Postflop with Insufficient Raise

Setup: Current bet: $100, Player current bet: $50, Player bank: $30

Action: Player clicks "Raise" button

Expected Result: System automatically sends all-in action with $30

Why: Minimum raise ($110) requires $60 additional, but player only has $30

Scenario 3: Sufficient Funds

Setup: Current bet: $50, Player current bet: $50, Player bank: $200

Action: Player clicks "Raise" button

Expected Result: System sends normal raise action with $60

Why: Player has sufficient funds for minimum raise

🔧 Server-Side Handling

The server-side logic remains unchanged and properly handles both raise and all-in actions:

PokerGame.js - raisePlayer() method:

// Validate that this is a valid raise
if (totalBetAmount <= this.currentBet) {
    throw new Error('Raise must be greater than current bet');
}

PokerGame.js - allInPlayer() method:

// For all-in, we don't need to validate against current bet
// because all-in is always a valid action regardless of the current bet
player.currentBet += allInAmount;
player.bank -= allInAmount;
this.pot += allInAmount;

⚠️ Important Notes:

  • This feature only affects the client-side raise button logic
  • Server-side validation remains unchanged for security
  • All-in actions are always valid regardless of current bet
  • The feature works in both multiplayer (FastGameScene) and AI (AIBotScene) modes
