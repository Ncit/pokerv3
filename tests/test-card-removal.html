📝 Expected Behavior

  • Room Reset: The room should reset to lobby state when a player leaves

🐛 Troubleshooting

  • Cards not removed: Check browser console for error messages
  • Server connection issues: Ensure server is running on port 3000
  • Multiple players needed: Test requires at least 2 players to join
  • Browser cache: Try hard refresh (Ctrl+F5) if UI doesn't update
