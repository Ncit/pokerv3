🎰 Three-Raise Limit Test

This test verifies that the poker game enforces a three-raise limit per betting round to prevent infinite loops.

Test Objectives:

  • ✅ Verify that only 3 raises are allowed per betting round
  • ✅ Confirm raise button is disabled after 3 raises
  • ✅ Test that raise counter displays correctly
  • ✅ Ensure raise limit resets for each new betting round
  • ✅ Verify all-in actions don't count against raise limit when they don't increase the bet

Expected Behavior:

  • Players can only raise up to 3 times per betting round
  • After 3 raises, only call/check/fold actions are allowed
  • Raise counter shows "Raises: X/3" during active betting
  • Raise limit resets when moving to flop, turn, river phases
  • All-in actions that don't increase the current bet don't count as raises

🧪 Test Instructions:

  1. Start the server: Run cd pokerv2/server && npm run dev
  2. Open this page in multiple browser tabs/windows to simulate multiple players
  3. Join the game with different player names in each tab
  4. Get ready in all tabs and start the game
  5. Test raise limit: Try to raise more than 3 times in a single betting round
  6. Verify UI: Check that raise button becomes disabled and counter shows "Raises: 3/3"
  7. Test phase reset: Complete the hand and verify raise limit resets for new betting rounds
