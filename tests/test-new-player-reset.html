🧪 Test New Player Reset

🎯 Test Objective
Verify that when a new player joins the game while other players are in the lobby (ready to start), the room automatically resets to allow the new player to participate from the beginning.
🔧 What Was Implemented
Added logic to automatically reset the room when a new player joins during lobby state, ensuring fair participation for all players.
Implementation Details:
  1. Server checks if game is in lobby state when new player joins
  2. If lobby has ready players, room is automatically reset
  3. All players are notified about the reset due to new player joining
  4. New player can now participate from the beginning
  5. Client shows notification about the reset
📋 Test Scenarios
Scenario 1: New Player Joins During Lobby
  1. Open the multiplayer game in 2 different browser tabs
  2. Join with 2 different players (e.g., Player 1, Player 2)
  3. Both players click "Ready"
  4. Open a third browser tab and join with a third player (Player 3)
  5. Verify that the room resets and shows notification about new player joining
  6. Verify that all 3 players are now in lobby state and can click "Ready"
Scenario 2: New Player Joins During Active Game
  1. Start a game with 2 players
  2. Play a few rounds
  3. Open a third browser tab and join with a third player
  4. Verify that the room does NOT reset (game continues normally)
  5. Third player should see they joined but game is in progress
Scenario 3: New Player Joins Empty Lobby
  1. Open the multiplayer game in 1 browser tab
  2. Join as the first player
  3. Open a second browser tab and join as second player
  4. Verify that no reset occurs (normal lobby behavior)
✅ Expected Results
Scenario 1: Room should reset when new player joins during lobby with ready players. All players should see notification: "[Player Name] присоединился к игре. Комната сброшена."
Scenario 2: Room should NOT reset when new player joins during active game. Game should continue normally for existing players.
Scenario 3: No reset should occur when joining empty lobby. Normal lobby behavior should be maintained.
⚠️ Important Notes
Server Restart Required: Make sure to restart the server after applying the fixes so that the updated server.js code is loaded.
Multiple Browser Sessions: Use different browser sessions or incognito windows to simulate different players joining the game.
Timing: The reset only happens when the game is in lobby state AND there are ready players. If the game has already started, new players join as spectators.
