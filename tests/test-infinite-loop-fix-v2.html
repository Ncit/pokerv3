🔧 Fix Details

This test verifies the fix for the infinite loop that occurred when:

  • All 5 community cards are dealt (river phase complete)
  • All players call/check after the river
  • The betting round should complete and move to showdown
  • Instead, the game gets stuck in an infinite loop

Root Cause:

// The issue was in the nextPlayer() method: if (this.isBettingRoundComplete()) { this.nextPhase(); // This calls startBettingRound() again } else { this.currentPlayer = nextPlayer; if (this.phase !== 'showdown') { this.startBettingRound(); // This can call nextPhase() again } } // And in nextPhase(): this.startBettingRound(); // This creates a circular call

Applied Fixes:

  1. Added showdown phase check in startBettingRound():
    // Don't start betting round if we're in showdown if (this.phase === 'showdown') { console.log('PokerGame: Cannot start betting round in showdown phase'); return; }
  2. Added showdown phase check in nextPhase():
    // Only start betting round if we're not transitioning to showdown if (this.phase !== 'showdown') { this.startBettingRound(); }
  3. Improved river phase completion logic:
    // OR if we're in river phase and all bets are equal (no more betting after river) const shouldComplete = (allBetsEqual && allHaveActed) || allAllIn || (this.phase === 'river' && allBetsEqual);
  4. Added comprehensive debug logging:
    console.log('PokerGame: Betting round complete, moving to next phase'); console.log('PokerGame: Continuing betting round, next player:', nextPlayer); console.log('PokerGame: Only one active player, moving to showdown');
