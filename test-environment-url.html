🌐 Environment URL Switching Test

Current Environment

Check the browser console to see the current environment information.

You can also use the environment switcher buttons in the top-right corner (in debug mode).

URL-Based Environment Switching

Add environment parameters to the URL to switch environments:

URL Examples (click to test):

Development: ?env=development
VKontakte: ?env=productionVK
Telegram: ?env=productionTelegram
Default (no parameter): Remove all parameters

Hash-Based Environment Switching

You can also use URL hash fragments:

Development: #dev
VKontakte: #vk
Telegram: #telegram

Console Commands

Use these commands in the browser console:

env.switch("dev") - Switch to development
env.switch("vk") - Switch to VKontakte
env.switch("telegram") - Switch to Telegram
env.info() - Show current environment info
env.list() - Show available environments
env.remove() - Remove environment from URL

Quick Switch Buttons

Click these buttons to quickly switch environments:

Development VKontakte Telegram Default

⚠️ Important Notes

  • Environment changes are applied immediately without page reload
  • URL parameters take priority over platform detection
  • Environment switching buttons only appear in debug mode
  • Check the browser console for detailed environment information
